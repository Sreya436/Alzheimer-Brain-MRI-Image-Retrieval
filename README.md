# Alzheimer-Brain-MRI-Image-Retrieval
Pattern Similarity Based Medical Image Retrieval Using MATLAB

**📌 Project Overview**

This project focuses on retrieving similar brain MRI images using image processing and pattern similarity techniques. It helps users find visually similar MRI images from a dataset by comparing image features.

**🎯 Objectives**

- To develop an MRI image retrieval system using MATLAB.
- To extract important features from brain MRI images.
- To compare images based on similarity.
- To retrieve the top 5 most similar images for a selected query image.

**⚙️ Technologies Used**

- MATLAB
- Image Processing Toolbox
- Machine Learning Toolbox
- Image Processing Techniques

**🔍 Working Principle**

1. Load the brain MRI image dataset.
2. Select a query MRI image.
3. Extract image features.
4. Calculate the distance between the query image and dataset images.
5. Retrieve and display the top 5 most similar images.

**📊 Output**

The system displays the selected query image along with the top 5 similar MRI images based on calculated distance.

Note: A smaller distance indicates greater similarity between images.

**💻 Requirements**

- MATLAB (R2016a or compatible version)
- Image Processing Toolbox
- Brain MRI image dataset

**🚀 Applications**

- Medical image retrieval
- Brain MRI image analysis
- Research and educational purposes
